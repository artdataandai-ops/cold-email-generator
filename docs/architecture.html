Cold-Email Research Pipeline

You type a company URL and (optionally) a LinkedIn profile. The system finds recent news, looks at the prospect's LinkedIn activity, ranks everything by "would this make a good icebreaker?", and writes a personalised cold email. Click any box below to see what it does.

What gets logged

Every run writes a JSON log to logs/<timestamp>_<id>.json with:

  • Inputs (everything you typed)
  • Each step's name, duration, status, input, output, cost delta
  • Cumulative cost
  • Final email + bundle
  • Any warnings (skipped steps, failed fetches)

Open one to debug "why didn't this find news?" or "why did it pick that item?".

What the system does NOT do

  • Doesn't send the email — you copy/paste it.
  • Doesn't store the prospect. Stateless per run; only the log is kept.
  • Doesn't invent facts. If research is empty, the email opens with a generic intro — never fabricated quotes.
  • Doesn't always beat bot-protected sites. That's why RSS + web search exist as parallel signals.
